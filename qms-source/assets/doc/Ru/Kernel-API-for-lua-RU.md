# Lua в ядре Ferrite Core

LuaJIT встроен в ядро Ferrite Core. Ядро создаёт состояние Lua, регистрирует
доступные функции, выполняет переданный скрипт и закрывает состояние после его
завершения. Это не отдельный пользовательский процесс: Lua-код выполняется
синхронно внутри вызывающего кода ядра.

В конфигурации сборки LuaJIT отключены JIT-компиляция и FFI. Ядро открывает
стандартные библиотеки Lua `base`, `math` и `string`. Остальные стандартные
библиотеки автоматически не открываются.

## Запуск скриптов

В shell команда `rl` принимает Lua-код прямо в аргументе:

```text
rl print("Привет из Ferrite Core")
```

Для чтения и выполнения скрипта из VFS укажите `-file` и путь:

```text
rl -file /scripts/hello.lua
```

Скрипт загружается как текст, завершающий нулевой байт добавляется ядром.
Необработанный вызов `lua_run_luac(char*)` также доступен коду ядра.

Каждый вызов `lua_run_luac` создаёт новое состояние Lua. Обычные Lua-переменные
и загруженные модули между запусками не сохраняются. Для небольших значений,
которые должны переживать отдельные запуски Lua, предусмотрено хранилище
`glob_*`.

## API ядра

Все функции ниже регистрируются в глобальном пространстве Lua при создании
состояния, если не указано иное.

### Глобальные функции

| Функция | Поведение |
|---|---|
| `print(value)` | Выводит первое значение в терминал и завершает вывод новой строкой. Для `nil` выводит пустую строку. |
| `printi(value)` | Выводит первое значение без автоматического перевода строки. |
| `clear()` | Очищает экран. |
| `k_req(name)` | Подключает один из модулей ядра `shell` или `easyinput`, создавая соответствующую глобальную таблицу. Возвращаемое значение использовать не нужно. |
| `glob_set(name, value)` | Сохраняет число, строку или boolean в общем хранилище. Передача `nil` удаляет значение с таким именем. |
| `glob_get(name)` | Возвращает сохранённое число, строку или boolean; если имени нет, возвращает `nil`. |
| `glob_free(name)` | Удаляет значение из общего хранилища. Если имени нет, ничего не делает. |

`glob_set` принимает только значения Lua типов `number`, `string`, `boolean` и
`nil`. Таблицы, функции и другие типы не поддерживаются и приводят к ошибке Lua.
Имена чувствительны к регистру.

Пример:

```lua
glob_set("player_name", "Mira")
glob_set("high_score", 1250)
glob_set("sound_enabled", true)

print(glob_get("player_name"))

glob_free("high_score")
glob_set("sound_enabled", nil) -- nil также удаляет значение
```

### Модуль `shell`

Подключается вызовом `k_req("shell")` и создаёт глобальную таблицу `shell`.

| Функция | Поведение |
|---|---|
| `shell.exec(command)` | Выполняет одну команду shell. Функция не возвращает статус выполнения. Команда запускается без повышенных прав. |

Пример:

```lua
k_req("shell")
shell.exec("help")
```

Команда выполняется с обычным контекстом shell. Не используйте `shell.exec`
для команд, которым необходимы права администратора.

### Модуль `easyinput`

Подключается вызовом `k_req("easyinput")` и создаёт глобальную таблицу
`easyinput`.

| Функция | Поведение |
|---|---|
| `easyinput.input()` | Блокирует выполнение текущего Lua-скрипта до нажатия Enter и возвращает введённую строку. Backspace удаляет последний введённый символ. |
| `easyinput.finput()` | Заглушка: сейчас не читает ввод, не приостанавливает выполнение и не возвращает значение. |

Текущая реализация `easyinput.input()` принимает печатные ASCII-символы
(коды 32–126). Некорректный для неё ввод, например не-ASCII символы, не
добавляется в возвращаемую строку. Размер строки ограничен доступной памятью
Lua; при нехватке памяти функция сообщает об ошибке Lua.

Пример:

```lua
k_req("easyinput")
printi("Ваше имя: ")
local name = easyinput.input()
print("Привет, " .. name)
```

Пока `easyinput.input()` ждёт клавиатурный ввод, выполнение этого Lua-вызова
не продолжается. Это синхронное ожидание, а не фоновый ввод.

### Таблица `serial`

Доступна без вызова `k_req`.

| Функция | Поведение |
|---|---|
| `serial.println(text)` | Отправляет строку в последовательный порт и завершает строку. Передавайте строку. |
| `serial.newline_m()` | Выводит ручной перевод строки в последовательный порт. |

Пример:

```lua
serial.println("Сообщение ядра")
serial.newline_m()
```

### Таблица `kernel`

Доступна без вызова `k_req`.

| Функция | Поведение |
|---|---|
| `kernel.version()` | Возвращает версию Ferrite Core (`FERR_VER`). |
| `kernel.qms_ver()` | Возвращает версию QMS (`CORE_VER`). |

Пример:

```lua
print("Ferrite Core " .. kernel.version())
print("QMS " .. kernel.qms_ver())
```

## Обработка ошибок и ограничения

- Ошибка загрузки или выполнения скрипта выводится ядром как `Lua error`.
- Ошибки аргументов API (например, неподдерживаемый тип в `glob_set`) становятся
  ошибками Lua и прекращают выполнение текущего скрипта.
- `k_req` распознаёт только точные имена `shell` и `easyinput`. Для неизвестного
  имени функция возвращает строку `invalid kernel module name`; исключение Lua
  при этом не создаётся.
- Встроенный `print` ядра выводит только первый аргумент. Для нескольких
  значений используйте конкатенацию Lua, например
  `print("score: " .. score)`.
- Поддержка Unicode зависит от клавиатурного драйвера и терминала; ввод через
  `easyinput.input()` в текущей реализации ограничен ASCII.
- Не считайте Lua-песочницу границей безопасности: скрипты выполняются внутри
  ядра и могут вызывать предоставленный API ядра.
